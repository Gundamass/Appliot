# 候选人档案字段选项设计

## 目标

修正候选人档案将枚举字段错误渲染为“是/否”的问题，建立可复用的跨招聘网站标准选项集，并为目标网站选项映射提供稳定语义。

## 设计原则

- 只有真实布尔语义字段显示“是/否”。
- 固定枚举字段使用集中维护的标准选项。
- 地址字段保持可自由输入，同时提供省市建议。
- 档案保存标准值；投递阶段再转换为目标网站的真实选项。
- 已保存但不在当前标准选项中的旧值必须继续显示和保存，不得静默丢弃。
- 所有界面文字使用中文。

## 字段元数据

扩展 `FieldDefinition`，为档案编辑控件增加独立于招聘网页字段类型的展示元数据：

- `profileControl: "text" | "textarea" | "date" | "boolean" | "enum" | "suggestion"`
- `profileOptions?: readonly string[]`

招聘网页兼容类型继续由现有 `types` 表示。档案页面不得再通过 `types.includes("radio")` 推断字段是否为布尔值。

## 标准选项

- 性别：男、女、其他、不愿透露。
- 国籍：常见国家或地区、其他；选择其他后允许保存用户输入值。
- 民族：完整 56 个民族。
- 政治面貌：中共党员、中共预备党员、共青团员、群众、民主党派成员、无党派人士、其他。
- 婚姻状况：未婚、已婚、离异、丧偶、其他、不愿透露。
- 证件类型：居民身份证、护照、港澳居民来往内地通行证、台湾居民来往大陆通行证、其他。
- 学历：高中及以下、大专、本科、硕士、博士、其他。
- 学历类型：全日制、非全日制、其他。
- 培养类别：统招、定向、委培、自筹、其他。
- 工作性质和用工类型：实习、全职、兼职、劳务、其他。
- 奖项级别：国家级、省级、市级、校级、院级、其他。
- 是否接受异地工作、是否接受出差、是否为最高学历：是、否。

## 地址输入

现居住地、户籍所在地、期望工作地点使用文本输入框和 `datalist` 建议。建议值覆盖直辖市、省会、计划单列市及常见招聘城市；用户仍可输入任意省市区文本。

## 旧值兼容

枚举控件渲染时，如果当前值不在标准选项中，则将当前值作为临时选项显示。用户不修改该字段时，保存流程不得更改原值。

国籍等允许“其他”值的字段采用可输入建议控件，避免用有限列表阻止真实资料录入。

## 投递映射

候选人档案只负责保存标准值。招聘页面自动填写继续读取页面真实 `options`，通过现有精确映射、选项归一化和受约束语义映射选择兼容值。无法唯一映射时进入审核或追问，不得猜测填写。

## 测试

- 性别显示正确枚举且不包含“是/否”。
- 政治面貌和民族包含规定选项。
- 布尔语义字段仍只显示“是/否”。
- 地址字段可以输入建议列表之外的值。
- 已有非标准值能够显示、编辑并保留。
- 重复经历中的学历、培养类别、用工类型和奖项级别使用各自选项。
- Web 全量测试、类型检查和候选人工作区浏览器测试通过。
